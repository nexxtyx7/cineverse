# CineVerse

Cinema virtual 3D para navegador, pronto para publicar no GitHub Pages ou Netlify.

## Recursos
- Cinema 3D navegável
- Personagem controlável com WASD/setas
- Controles para celular
- Poltronas selecionáveis
- Catálogo de filmes e séries
- Pesquisa
- Player HTML5
- Interface em português

## Adicionando conteúdo autorizado
1. Coloque o arquivo de vídeo em `movies/`.
2. Abra `script.js`.
3. Adicione/edite um item no array `catalog`.
4. Informe o caminho do vídeo em `video`.

Exemplo:
`video:"movies/meu-filme.mp4"`

**Importante:** use somente filmes, séries e outros vídeos que você tenha autorização para distribuir/reproduzir.

## Publicar
No GitHub, envie todos os arquivos do projeto para um repositório. Para GitHub Pages, deixe `index.html` na raiz e ative Pages nas configurações do repositório.
